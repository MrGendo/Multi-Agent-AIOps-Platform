## 任务 5: 沙箱验证进研判路径 + 落地页语义判定 (v2)

### 目标

(先取证后研判), 验证内容从数值字段升级为页面语义 (DOM 表单检测 + 截图视觉仿冒判定)。

### 实现方式
- link_verifier: 轮询成功后拉 DOM (API-Key, 截断 300KB) 做密码表单静态检测
  (密码框 + form action 域比对), 拉截图 (≤3MB) 喂 router 视觉模型判"声称身份/
  索取凭据/仿冒对象" (LandingPageJudgement 结构化, 枚举归一防自造词)

  超时取消后补告知 — format_sandbox_evidence 只取已验证事实

  注入 _USER_TMPL, haystack 同步扩展) → report (result.sandbox_link_verdicts)

- 前端: 流水 verify 阶段前移; 验证卡升级 (语义判定优先于 score 亮徽章:
  仿冒红/含密码表单琥珀/干净绿/不可达/超时未参与)
